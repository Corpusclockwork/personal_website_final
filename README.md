## Hello :)
This is a GitHub repository for my personal website, I used React, NodeJS and EpxressJS to make it. I am hosting it on an AWS server with a git cloned copy of my repo, and am using Cloudflare for domain management. I wanted a backend to host my images, and also thought it would be useful to already have a backend if I ever wanted to add more functionality in the future.
