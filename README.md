## Hello :)
This is a GitHub repository for my personal website, I used React, Next.js and Express.js to make it. I am hosting it on an AWS server with a git cloned copy of my repo, and am using Cloudflare for domain management. I wanted a backend to host my images, which was probably overkill and not smart, but maybe it'll be useful to already have a backend if I ever want to add more functionality.
